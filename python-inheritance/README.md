# python-inheritance

I am working on a Python project about inheritance, `isinstance`,
`issubclass`, and building classes on top of other classes.

| File | Description |
|------|-------------|
| `0-lookup.py` | Returns the attributes and methods of an object |
| `1-my_list.py` | `MyList` class that inherits from `list` |
| `2-is_same_class.py` | True if the object is exactly an instance of a class |
| `3-is_kind_of_class.py` | True if instance of a class or a subclass |
| `4-inherits_from.py` | True if instance of a subclass only |
| `5-base_geometry.py` | Empty `BaseGeometry` class |
| `6-base_geometry.py` | `BaseGeometry` with `area()` |
| `7-base_geometry.py` | `BaseGeometry` with `integer_validator()` |
| `8-rectangle.py` | `Rectangle` with validated private size |
| `9-rectangle.py` | `Rectangle` with `area()` and `__str__` |
| `10-square.py` | `Square` that inherits from `Rectangle` |
| `11-square.py` | `Square` with its own `__str__` |
| `tests/` | Doctests for tasks 1 and 7 |
