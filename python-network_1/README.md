# python-network_1

I am working on a project about making HTTP requests in Python with
`urllib` and `requests`: reading headers, sending POST data, handling
error codes, using a JSON API and Basic Authentication.

| File | Description |
|------|-------------|
| `0-hbtn_status.py` | Fetches a status page with `urllib` |
| `1-hbtn_header.py` | Displays `X-Request-Id` with `urllib` |
| `2-post_email.py` | POSTs an email with `urllib` |
| `3-error_code.py` | Handles `HTTPError` with `urllib` |
| `4-hbtn_status.py` | Fetches a status page with `requests` |
| `5-hbtn_header.py` | Displays `X-Request-Id` with `requests` |
| `6-post_email.py` | POSTs an email with `requests` |
| `7-error_code.py` | Prints the error code if status >= 400 |
| `8-json_api.py` | Searches a user through a JSON API |
| `10-my_github.py` | Displays a GitHub user id with Basic Auth |
