# python-test_driven_development

I am working on a Python project about test driven development:
writing docstrings, interactive tests with `doctest`, and unit tests
with `unittest`.

| File | Description |
|------|-------------|
| `0-add_integer.py` | Adds 2 integers (floats are cast) |
| `2-matrix_divided.py` | Divides all elements of a matrix |
| `3-say_my_name.py` | Prints `My name is <first name> <last name>` |
| `4-print_square.py` | Prints a square with `#` |
| `5-text_indentation.py` | Prints a text with 2 new lines after `.`, `?` and `:` |
| `6-max_integer.py` | Finds the max integer in a list |
| `tests/*.txt` | Doctests for each function |
| `tests/6-max_integer_test.py` | Unittests for `max_integer` |
