# python-network_0

I am working on a project about HTTP and the `curl` command: sending
requests with different methods, headers and parameters, and reading
the responses.

| File | Description |
|------|-------------|
| `0-body_size.sh` | Displays the size of the response body in bytes |
| `1-body.sh` | Displays the body of a GET request (only if status is 200) |
| `2-delete.sh` | Sends a DELETE request and displays the body |
| `3-methods.sh` | Displays the HTTP methods the server accepts |
| `4-header.sh` | Sends a GET request with a custom header |
| `5-post_params.sh` | Sends a POST request with `email` and `subject` |
